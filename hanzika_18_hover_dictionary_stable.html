Markdown tables or CSV, up to a few hundred rows

What format should the file be?

Markdown files should contain one or more tables with these columns (header row required):

Hanzi · Pinyin · Meaning · Example (中文) · Translation · HSK · Tags

Only Hanzi, Pinyin and Meaning are required — the rest are optional. Pinyin uses tone marks with syllables separated by spaces (e.g. mǐ fàn). The template file works as-is. CSV files use the same columns.
